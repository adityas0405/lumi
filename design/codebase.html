Every line is read from the code

Boxes and arrows come from imports, call sites and the diff. The model picks which diagram fits and writes the labels. Anything it names that isn't in the code is dropped, the same rule as for citations.

One diagram system

The same component draws the Codebase page, renders into the video, and runs live in the player. Pausing turns the picture into the real thing: each part opens its code, and Ask can answer about what's selected.

Motion explains, then stops

The map draws in the direction its arrows read. The trace follows the path the code runs. The table moves only the cells that changed. Nothing loops, and reduced-motion settings turn it all off.
